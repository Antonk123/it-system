Teckenförklaring

    Kolumnerna följer flödet vy → frontend-JS → API-route → service → data. Kartan är en ögonblicksbild som checkats in i git och uppdateras inte automatiskt när koden ändras. Markering visar beroenden i kartan, inte ett verifierat körflöde.
