# Triage Labels

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Fully specified for an agent |
| ready-for-human | ready-for-human | Human implementation needed |
| wontfix | wontfix | Will not be actioned |

When a skill mentions a triage role, use its tracker label above.
Edit the tracker-label column to change the vocabulary.
